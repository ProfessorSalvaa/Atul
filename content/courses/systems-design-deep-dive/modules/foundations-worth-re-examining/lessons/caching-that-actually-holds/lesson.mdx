Generated diffs and unfamiliar code reward a different reading strategy than writing from scratch. Start by asking what changed in _intent_ — then verify only the lines that affect behavior you actually care about.

```javascript
function summarize(rows) {
  return rows
    .filter((r) => r.active)
    .map((r) => r.value)
    .reduce((sum, v) => sum + v, 0);
}
```

Notice the filter-map-reduce chain reads almost like a sentence. That's not an accident — it's the fastest shape to verify at a glance, which matters most in exactly the situation this lesson is about: **Caching That Actually Holds Up**.
