This lesson is part of **The Anatomy of a Good Prompt** in _Prompt Engineering Fundamentals_. By the end, you should be able to put the following into practice:

- A zero-shot prompt asks directly with no example; a few-shot prompt includes 1-3 examples of the input/output pattern you want
- Few-shot prompting is the single highest-leverage technique for controlling tone and structure — models imitate the pattern you show far more reliably than a text description of the pattern
- Keep examples short and representative rather than exhaustive — 2-3 tight examples usually outperform one long one

```text
Turn this into 3 examples of a few-shot prompt for writing product update emails:

Example 1:
Input: Fixed a bug where exports timed out on large files.
Output: "Exports are now reliable, even for your biggest files — no more timeouts."

Example 2:
Input: Added dark mode.
Output: "Dark mode has arrived. Toggle it in Settings > Appearance."

Now write one for: Added CSV import for contacts.
```
